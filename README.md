# Type Sprint

A typing speed test with live WPM and accuracy, 30s/60s modes, and a device-saved history chart
of your last 10 runs. The clock starts on your first keystroke.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/type-sprint/

Pure client-side HTML/CSS/JS.
